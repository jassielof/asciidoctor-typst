== Installing

Download {product} and verify the checksum.footnote:[Use `sha256sum` on Linux.]
Then run it:

[source,sh]
----
$ zigc --version
0.1.0
----

.Hello world
[source,zig]
----
const std = @import("std"); // <1>

pub fn main() void { // <2>
    std.debug.print("hi\n", .{});
}
----
<1> Import the standard library.
<2> The entry point.

WARNING: Do not run this as root.

[TIP]
.A tip with a title
====
Prefer `zig build` over invoking the compiler directly.
====
